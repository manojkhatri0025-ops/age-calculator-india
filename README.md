# Age Calculator India

A polished, privacy-first, browser-only age calculator website prototype.

## Run locally

From this folder, run any static server, for example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Included

- Exact age calculator (years, months, days, total days/weeks/months)
- Leap year and February 29 handling
- Age difference calculator
- Birthday countdown
- Dark mode
- Copy, share and print actions
- Shareable result links that reload the calculation from URL parameters
- Professional light/dark theme toggle
- Responsive mobile layout
- SEO metadata and JSON-LD
- No login, no database, and no calculator data sent to a server
